# بوست Loraneem Tech — مباركة إطلاق التطبيق

بوست 4:5 بصوت صفحة **Loraneem Tech** يبارك إطلاق تطبيق **المكتب العقاري الإلكتروني — السويداء** ويقدّمه بالصيغة المعتمدة: **«باكورة أعمالنا»**.

## الملفات الجاهزة

- `loraneem_congrats_feed_1440x1800.jpg` — نسخة النشر على فيسبوك/إنستغرام.
- `loraneem_congrats_feed_1440x1800.png` — الأصل عالي الجودة.
- `CAPTION_AR.txt` — النص الجاهز للنسخ والنشر.
- `Loraneem_Launch_Post_Ready.zip` — حزمة النشر الخفيفة (JPG + الكابشن).
- `build_launch_post.py` — ملف البناء القابل لإعادة الإنتاج.

## القرار البصري

- Loraneem هي مرسل المباركة، لذلك يظهر شعارها الرسمي كاملاً في الأعلى وبألوانه الأصلية.
- شعار المكتب هو مشروع الإطلاق وبطل منتصف التصميم.
- الجسر اللوني يجمع سماوي/أخضر/بنفسجي Loraneem مع ذهب المكتب من دون إعادة تلوين أي شعار أو قصّه أو تمديده.
- لا يوجد رابط تحميل داخل التصميم لأن الرابط الرسمي لم يُثبت في هذه الجولة.
- هذا المسار تسويقي فقط؛ لم تُعدّل أي ملفات من كود التطبيق.

## إعادة البناء

من جذر المستودع:

```bash
python3 -m pip install --target /tmp/posterdeps \
  pillow numpy qrcode uharfbuzz freetype-py
PYTHONPATH=/tmp/posterdeps \
  python3 marketing/loraneem_launch_congrats/build_launch_post.py
```

يستخدم البناء حل HarfBuzz + FreeType المعتمد في حملة الشكر، لمنع ظهور محارف عربية ناقصة مع خط Cairo.
