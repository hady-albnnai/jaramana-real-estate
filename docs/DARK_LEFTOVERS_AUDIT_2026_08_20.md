## 🧪 للتحقق بعد `git pull` + `flutter run`
1. **حجز موعد** على أي عرض → الحوار فاتح والنصوص ظاهرة (الرقم، رمز OTP، التعليمات).
2. حاول حجز موعد **على عرضك أنت** → رسالة المنع ظاهرة.
3. حجز بلا تسجيل دخول → رسالة «يجب تسجيل الدخول» ظاهرة.
4. **لوحة المحامي** → فتح تفاصيل استشارة → العنوان وأيقونة الإغلاق ظاهران.
5. **الإدارة ← المدفوعات** → إلغاء دفعة → صندوق التحذير وحقل السبب مقروءان.
6. **مواعيدي** → بطاقة «يوجد طلب حجز موعد بتاريخ…» ظاهرة.
