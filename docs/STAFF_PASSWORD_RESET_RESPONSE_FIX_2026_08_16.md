# إصلاح إعادة تعيين كلمة مرور الموظف — 2026-08-16

## العطل

`admin_reset_staff_password` تعيد JSONB بالشكل `{success:true}`، بينما Edge `reset-user-password` كانت تتحقق من `data === true` فقط.

النتيجة الخطرة:
- كلمة المرور تتغير فعلياً إلى كلمة عشوائية.
- Edge ترجع `success=false`.
- الواجهة لا تعرض الكلمة الجديدة وتقول «خطأ غير معروف».
- الموظف يفقد القدرة على الدخول ولا يعرف الكلمة الجديدة.

## الإصلاح

Edge تقبل الآن كلا الشكلين:
- boolean `true` للتوافق القديم.
- JSONB `{success:true}` للدالة الحية.

لا تُعاد `new_password` إلا بعد نجاح مؤكد. عند فشل الدالة تُعاد رسالة خطأ ولا تُعرض كلمة مولدة غير مطبقة.

الحساب المتأثر وقت التشخيص:
- الاسم: موظف رئيسي
- username: office1
- role: 4
