# شاشة المصور الكاملة — 2026-08-17

## قرارات المالك

- المصور يستطيع تعديل موعد التصوير مباشرة، دون انتظار موافقة الإدارة.
- التواصل من الشاشة يكون باتصال هاتفي مباشر فقط.

## الوظائف

### لوحة العمل
- ملخص للحالية، القريبة، المسلّمة للمكتب والمكتملة.
- تبويبات: الحالية، القادمة، المنفذة.
- الحالية تشمل غير المجدولة والمتأخرة كي لا تختفي أي مهمة نشطة.
- القادمة مرتبة زمنياً مع تقويم شهري يعمل بحسب الشهر المختار.
- سحب للتحديث ومعالجة فشل التحميل بزر إعادة المحاولة.

### تفاصيل المهمة
- حالة المهمة.
- نوع العرض والعملية والسعر.
- المدينة والموقع العام.
- وصف العقار وكل المواصفات المدخلة.
- اسم صاحب الطلب ورقم هاتفه.
- الموعد باليوم والساعة.
- ملاحظات المكتب.
- الصور المرفوعة في المهام المسلّمة أو المكتملة.

### الإجراءات
- اتصال مباشر بصاحب الطلب.
- تحديد أو تعديل الموعد مباشرة.
- فحص تعارض مواعيد المصور سيرفرياً.
- إشعار صاحب الطلب والإدارة فور تعديل الموعد.
- بدء المهمة.
- الاعتذار بسبب إلزامي وإعادتها للإدارة.
- التصوير مباشرة بالكاميرا أو اختيار عدة صور من المعرض.
- معاينة الصور وحذف غير المناسب قبل الرفع.
- إضافة ملاحظة المصور.
- إرسال الصور للمكتب مع منع التسليم بلا صور.
- معالجة فشل الرفع أو التسليم برسالة عربية مع إبقاء المهمة قابلة لإعادة المحاولة.
- إعادة تنفيذ مهمة صور مرفوضة وتسليمها مجدداً.

## حماية السيرفر
- المصور لا يستطيع تعديل موعد مهمة ليست مسندة له.
- تعديل الموعد متاح للحالات النشطة أو المرفوضة فقط.
- الموعد الماضي مرفوض.
- تعارض الموعد مع مهمة أخرى مرفوض.
- إشعارات الإدارة محصورة بالأدوار 3–6.
