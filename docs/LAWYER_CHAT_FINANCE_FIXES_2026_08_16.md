# إصلاحات تجربة المحامي ومؤشرات المحادثة وحصة 50% — 2026-08-16

## البلاغات

- تأخر Push «المحامي جاهز» حتى عامل الدقيقة.
- بطاقة المحامي تعرض «إتمام» أثناء المحادثة وتعيد نداء الجاهزية عند الفتح.
- إشعارات المحامي وتفاصيل حسابه تُردان للرئيسية.
- تبويب إضافة المهمة يظهر فارغاً/معلقاً.
- مؤشرات الإرسال والقراءة غير واضحة.
- المطلوب: حصة المحامي 50%، ولا يرى المستخدم أي تفصيل مالي داخلي.

## الإصلاح

- Push فوري عند الجاهزية، وOutbox يبقى fallback فقط ويُعلّم sent عند نجاح الفوري.
- `get_lawyer_consultations` يعيد `session_status/starts/ends` من جلسة V2.
- زر البطاقة يعتمد session: ready يرسل الجاهزية، join_window/active يفتح فقط.
- حذف زر الإتمام أثناء الجلسة؛ النهاية خادمية عند انتهاء الوقت.
- الدوران الجانبيان محامٍ/معقّب يرثان `userProfile` فقط، بلا أي إدارة.
- تحميل تبويب المهمة ينتظر جلب المعقبين، مع مؤشر تحميل؛ API الحي يعيد معقبين اثنين.
- داخل فقاعة رسالة المرسل يظهر «تم الإرسال» أو «تمت القراءة» بوضوح، وحدث القراءة يعيد الجلب بعد debounce.
- `legal_finance_config` محمي service_role فقط وبنسبة 50%.
- `lawyer_earnings` دفتر ذري مرتبط بالدفعة والاستشارة والجلسة/الموعد.
- الحالة pending ثم earned عند نهاية الهاتفية/إكمال الحضورية/إلغاء المستخدم بلا استرداد، وreversed عند عكس الدفع.
- إعادة الإسناد تنقل القيد pending للمحامي الجديد.
- المستخدم يبقى يرى السعر الكامل؛ نسبة المحامي لا توجد في app_config العامة.
- بطاقة المحامي تعرض «حصتك» فقط، وتبويب «مستحقاتي» يعرض pending/earned والتفاصيل دون حصة المكتب.
