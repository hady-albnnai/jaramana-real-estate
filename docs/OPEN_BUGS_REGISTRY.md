## BUG-001 — 🔴 زر ميت: «إدارة الموظفين» بمركز عمليات المكتب

| | |
|---|---|
| **الملف** | `lib/screens/admin/office_operations_screen.dart:106` |
| **الشاشة** | `/admin/office-operations` — «مركز عمليات المكتب» |
| **الخطورة** | 🔴 عالية — شاشة خطأ للمدير |
| **الحالة** | مفتوح — مؤجّل بقرار المالك |

**الوصف**: البند يوجّه إلى `'/admin/employees'`، وهذا المسار **غير مسجَّل إطلاقاً**
في `lib/core/router/app_router.dart`. المسار الصحيح المسجَّل هو
`'/admin/employee-management'` (السطر ~299).

**الأثر**: المدير يضغط «إدارة الموظفين» ← go_router يرمي شاشة خطأ.
البند المماثل في `/admin/sections:71` **سليم** — الخلل محصور بشاشة عمليات المكتب.

**الإصلاح المقترح** (سطر واحد):
```dart
'route': '/admin/employee-management',
```

**قبل الإصلاح**: تحقّق أن `PermissionKeys.manageStaff` هو نفس الصلاحية التي
يشترطها `_adminRoutePermission('/admin/employee-management')` وإلا صار الزر
ظاهراً ثم مرفوضاً.

## BUG-004 — 🟠 قائمة `ALLOWED_TEXT_KEYS` ناقصة في `admin-config`

| | |
|---|---|
| **الملف** | `supabase/functions/admin-config/index.ts:21-25` |
| **الخطورة** | 🟠 متوسطة — لا يظهر اليوم، فخّ مستقبلي |
| **الحالة** | مفتوح |

الفعل `update_texts` يقبل 3 مفاتيح فقط:
`videoRequestWhatsApp`, `videoRequestGroupLink`, `appDownloadLink`.

مفاتيح `txts.facebook`, `txts.instagram`, `txts.socialPages`,
`txts.developerPhone`, `txts.developerPhone2` **ليست فيها** — تُحفظ اليوم فقط
لأن محرّر الإعدادات يمرّ عبر `update_sections` (حيث `txts` قسم مسموح ويُدمج
دمجاً سطحياً بلا تحقُّق). أي انتقال مستقبلي إلى `update_texts` سيُسقطها بصمت.

**تحذير إضافي**: مسار `update_sections` **لا يُنظِّف ولا يتحقّق** من محتوى
`txts` إطلاقاً (لا `cleanText` ولا تحقُّق مخطط الرابط) — على عكس
`payChannels` و`office` و`legalPrice` التي لكلٍّ منها قائمة بيضاء وتحقُّق.

## BUG-005 — 🟠 `txts` غير محصَّن بقائمة بيضاء في `update_sections`

| | |
|---|---|
| **الملف** | `supabase/functions/admin-config/index.ts:254-261` |
| **الخطورة** | 🟠 متوسطة |
| **الحالة** | مفتوح |

المسار الافتراضي `value[k] = { ...cur, ...v }` يقبل **أي** مفتاح داخل `txts`
وبأي نوع، من أي حساب دوره ≥ 5. لا تنظيف، لا حد أطول، لا تحقُّق `https://`.
كل الأقسام الأخرى محصَّنة — `txts` هو الثغرة الوحيدة المتبقية.

## BUG-008 — 🔴 استيراد مكسور يُفشل البناء ✅ مُصلح 2026-08-14

| | |
|---|---|
| **الملف** | `lib/widgets/offer_filters.dart:2-3` |
| **الخطورة** | 🔴 **قاتلة — كانت ستُفشل البناء بالكامل** |
| **الحالة** | ✅ مُصلح |

```dart
import '../../core/theme/app_theme.dart';   // ← يحلّ إلى core/ بجذر الريبو
import '../../models/offer_model.dart';     // ← يحلّ إلى models/ بجذر الريبو
```

`lib/widgets/` + `../../` = **جذر الريبو**، ولا يوجد هناك `core/` ولا `models/`.
الصحيح مستوىً واحد (`../`) للوصول إلى `lib/`.

**لماذا لم يظهر سابقاً**: الملف مضاف منذ كوميت `ed4dd48` ومستورَد فعلياً من
`user_home_screen.dart:11` و`visitor/home_screen.dart:7`، لكن كل الفحوص
السابقة كانت `dart format` الذي يفحص **التركيب فقط** لا حلّ المسارات.
اكتُشف بفحص §14 الآلي لكل الاستيرادات.

**الدرس**: `dart format` وحده لا يكفي — فحص المسارات إلزامي قبل كل بناء،
وهذا بالضبط ما تنصّ عليه §14 من الدستور.
