# 🔄 مخطط التجديد — ببساطة

## المسار الرئيسي (سطر واحد):

```
⏰ خلص وقت المحادثة
        │
        ▼
🟡 تضغط «تجديد المحادثة»
        │
        ▼
💳 شاشة الدفع — تدفع 500
        │
        ▼
⏳ «دفعتك قيد مراجعة الإدارة»   ← هون بتستنى (عادة ساعة)
        │
        ▼
✅ الإدارة تقبل الدفعة
        │
        ▼
💬 المحادثة ترجع — «بانتظار استئناف المحامي»
        │
        ▼
👨‍⚖️ المحامي يضغط «أنا جاهز»
        │
        ▼
🔔 يصلك إشعار «افتح المحادثة خلال دقيقتين»
        │
        ▼
🙋 تدخل خلال دقيقتين
        │
        ▼
⏱️ يبدأ عداد جديد كامل (15 دقيقة) — والمحادثة مكملة بنفس المحامي
```

## الاحتمالات الجانبية (بسيطة):

```
┌─────────────────────────────────────────────────────────────┐
│ أثناء «قيد المراجعة» (أثناء الانتظار):                     │
│   • زر «فتح المحادثة المرتبطة» → تشوف الرسائل القديمة       │
│   • زر «تحديث الحالة» → يحدّث الشاشة بلا ما يصفّرها          │
│   • ❌ ما في زر دفع ثاني — ممنوع الدفع المكرر                │
│                                                             │
│ فور اعتماد الإدارة: المحادثة تفتح لحالها تلقائياً —          │
│ ما بتكتب موضوع جديد وما بتدفع مرة ثانية.                     │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
│ لو الإدارة رفضت الدفعة:                                     │
│   → بطاقة «الدفعة مرفوضة» + السبب + زر «إعادة المحاولة»     │
│   (نفس المحادثة — ما بتبدا من الصفر)                        │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
│ لو المحادثة أقدم من 7 أيام:                                 │
│   → ما بيظهر زر تجديد أصلاً — لازم استشارة جديدة            │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
│ لو عندك دفعة معلّقة أصلًا (قيد المراجعة):                   │
│   → أي محاولة دفع ثانية توقفك عند «قيد المراجعة»            │
│     (حارس — ما بتتكرر الدفعات)                              │
└─────────────────────────────────────────────────────────────┘
```

## سؤال وجواب سريع

| سؤالك | الجواب |
|---|---|
| بعد ما أدفع، ليش تظهر «قيد المراجعة»؟ | الإدارة لازم توافق على الدفعة (هذا نظام الدفع بالتحويل) |
| ليش المحادثة ما فتحت لحالها بعد الدفع؟ | لأن الاعتماد هو اللي بيفتحها — وبعد الإصلاح تفتح **تلقائياً** فور الاعتماد |
| ليش لازم المحامي يضغط «أنا جاهز»؟ | لأن وقته (العداد) لا يُحتسب إلا لما يبدأ هو — يحميك من ضياع وقتك |
| كم مرة بيدفع؟ | مرة واحدة لكل تجديد — ولا يمكن تكرار الدفع |
