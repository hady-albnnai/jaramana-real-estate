## المرحلة التالية — P0

**Prototype بصري معزول**، وليس ربطاً بالزائر أو المستخدم أو الوسيط.

اختبر أولاً:

- بطاقة بيضاء فاخرة.
- زوايا 24px.
- تعتيم 20%.
- حد وسهم ذهبيان.
- ظل ناعم.
- تموضع ذكي.
- RTL وSafeArea وTextScale 2.0.

- Reduce Motion.

## ممنوع قبل نجاح P0

- لا تبدأ جولة الزائر أو المستخدم أو الوسيط.
- لا تعدّل منطق الدفع أو الحجز أو المطابقة.
- لا تعدّل Providers التجارية أو SQL أو Edge Functions، باستثناء حماية Idempotency المعتمدة صراحة في الخطة.
- لا تستخدم `E2E` كمرساة بصرية.
- لا تضع منطق الجولة داخل الشاشات دون Controller مركزي.

## قواعد كل مرحلة

1. افحص `git status` و`git diff` قبل وبعد العمل.
2. استخدم commit مستقلاً برمز المرحلة (`P0`، `P1`…).
3. لا تنتقل للمرحلة التالية قبل معيار خروج المرحلة الحالية.
4. حدّث `docs/USER_GUIDE_IMPLEMENTATION_STATUS_AR.md` بعد كل نقطة توقف.
5. عند فقدان التواصل، ابدأ من سجل الحالة لا من ذاكرة المحادثة.
