# تفاصيل طلب التصوير للمستخدم — 2026-08-17

## المتطلب

يستطيع صاحب الطلب متابعة كل البيانات التي أرسلها منذ أن يكون الطلب قيد مراجعة الإدارة، وبعد قبول الطلب يرى المصور وموعد التصوير المحدد.

## التنفيذ

- إثراء `my_photo_requests` بعد التحقق من هوية صاحب الطلب فقط.
- إرجاع نسخة آمنة من بيانات العرض المرتبط:
  - العنوان، النوع، العملية، السعر والعملة.
  - الموقع العام، الوصف، المواصفات.
  - رقم التنسيق، نوع الوثيقة، وحالة العرض التقنية.
- عند إسناد المصور تُعاد أيضاً:
  - اسم المصور.
  - هاتف المصور.
  - موعد التصوير.
- أضيف زر «عرض تفاصيل طلب التصوير» على كل بطاقة طلب.
- حالات المستخدم أصبحت واضحة:
  - قيد مراجعة الإدارة.
  - تم قبول الطلب وجارٍ تنسيق الموعد.
  - تم قبول الطلب وتحديد الموعد.
  - قيد التنفيذ / مرسلة للمكتب / مكتملة / مرفوضة / ملغاة.
- لا تُكشف هذه التفاصيل لأي مستخدم آخر؛ الإثراء يأتي بعد مطابقة الجلسة مع `requested_by`.
