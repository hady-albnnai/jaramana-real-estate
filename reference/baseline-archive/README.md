# أرشيف خط الأساس التاريخي — ممنوع النشر

هذا المجلد يحفظ مواد المصدر التاريخية التي كانت موجودة عند فصل مستودع جرمانا في
`backup-jaramana-pre-repository-cleanup-20261013-001`.

- ليس جزءاً من تطبيق جرمانا ولا من مسار نشره.
- لا تشغّل منه `migration` أو `function` أو `cron` أو سكربت أو أدوات تسويق.
- لا تنقل منه بيانات أو حسابات أو صور أو مفاتيح أو إعدادات نشر.
- عند الحاجة، يؤخذ منه منطق محدد فقط بعد جرد حي ومراجعة واعتماد ملف جديد باسم جرمانا.

المسار التشغيلي الجديد لجرمانا هو `supabase/` في جذر المستودع، وهو فارغ عمداً حتى يبدأ بناء جرمانا المنتقى.
