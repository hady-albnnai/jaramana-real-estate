# المكتب العقاري الالكتروني - جرمانا

هذا مجلد تجهيز مواد التوزيع الخاصة بجرمانا فقط.

لا يوجد حتى الآن رابط APK عام أو قناة توزيع أو صفحة سوشيال معتمدة. تُضاف هذه المعلومات بعد اعتمادها، مع هوية جرمانا وأرقام المكتب الرسمية فقط.

الصفحات القانونية داخل `legal/` مسودات جرمانا قابلة للمراجعة القانونية قبل الإطلاق.
