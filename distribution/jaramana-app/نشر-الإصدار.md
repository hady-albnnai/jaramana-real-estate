# قائمة تجهيز توزيع جرمانا

حالة التوزيع: غير مفعّل بعد.

قبل أول إصدار عام:

1. اعتماد اسم مستودع/قناة التوزيع وصفحة التحميل الخاصة بجرمانا.
2. إنشاء مفتاح توقيع Android جديد خاص بجرمانا وحفظه خارج Git.
3. إضافة إعدادات Supabase وFirebase جرمانا عبر البيئة الآمنة.
4. التأكد من نجاح الاختبارات وAndroid Release build.
5. مراجعة الصفحات القانونية وأرقام التواصل وروابط السوشيال المعتمدة.
6. توثيق رقم الإصدار وchecksum لملف APK المنشور.

لا تستخدم رابط توزيع أو مفتاح توقيع أو مشروع Supabase أو سكربت نشر تابع لأي مشروع آخر.
